# Meta Tags: Titles and Descriptions

Conventions from Google Search Central, Yoast, and 2026 audit practice. Titles affect ranking and CTR; descriptions affect CTR only, and Google rewrites 60-70 percent of them.

## 1. Audit checklist

- One meta title per URL, unique across the site. Flag duplicates with Screaming Frog, Sitebulb, or GSC HTML improvements.
- One meta description per URL, unique. Empty is better than duplicated boilerplate.
- Meta title differs from H1. Title targets the query contract; H1 targets the on-page promise.
- No keyword stuffing. One primary topic per title.

## 2. Title rules

- Length: 50-60 characters or about 580 px. Front-load the primary keyword within the first 40 characters so truncation on mobile keeps meaning.
- Pattern: `Primary Keyword + Value/Angle | Brand`. Example: `Technical SEO Audit Checklist 2026 | Acme`.
- Write for humans first: action verb or outcome (`Learn`, `Fix`, `Compare`), not slogans.
- Pipes separate ideas. Avoid all-caps and competitor brand stuffing.
- Each title must work as a query contract: a searcher can predict what the page delivers.

## 3. Description rules

- Length: 140-160 characters, 1-3 complete sentences. Keep the payload in the first 120 characters for mobile cut-off.
- Pattern by intent:
  - How-to: `Learn how to + topics + outcome.`
  - Commercial: `Compare + options + differentiator + CTA.`
  - Transactional: `Get + offer + proof + CTA.`
- Always include the focus keyphrase once, active voice, and one CTA (`Learn`, `See`, `Try`).
- Include a spec when it pre-qualifies the click: price, count, year, level.
- Never duplicate the title text. Expand it with the why-click reason.

## 4. Title versus H1

- Title lives in SERP. H1 lives on the page. They should share the topic but not match verbatim.
- Title example: `Internal Linking Guide: Topic Clusters That Rank | Acme`.
- H1 example: `Build internal links around one pillar per cluster`.
- H1 can be longer and more conversational; it confirms the visitor arrived correctly.

## 5. Rewrite defense

- Because Google rewrites most descriptions, the first paragraph must restate the value in 40-60 words so the engine has a clean fallback snippet.
- Keep title intent and H1 intent aligned, or rewrites drift toward H1 text.
