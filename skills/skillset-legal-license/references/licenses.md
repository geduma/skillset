# Bundled license texts

`assets/licenses/` contains the full official verbatim text of:

- `agpl-3.0.txt` — GNU AGPL v3.0
- `gpl-3.0.txt` — GNU GPL v3.0
- `lgpl-3.0.txt` — GNU LGPL v3.0
- `mpl-2.0.txt` — Mozilla Public License 2.0
- `apache-2.0.txt` — Apache License 2.0
- `mit.txt` — MIT License
- `bsd-3-clause.txt` — BSD 3-Clause License

For any license outside this list (e.g. PolyForm Noncommercial, Business Source License, or a custom proprietary license), look up the official text on the web and copy it verbatim, or confirm the exact text with the user. Never generate legal text from memory.
