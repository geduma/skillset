# SEO Content

Audits and improves on-page SEO content so each page matches intent, earns the click, and is easy to scan for users and search engines.

## When to use this

- The user asks to write, review, or fix titles, descriptions, headings, or body content.
- The user mentions search intent, TLDR, table of contents, FAQ, internal links, or content structure.
- CTR is low despite impressions, or snippets and FAQ rich results are missed.
- Headings are duplicated, flat, or H1 repeats the meta title verbatim.

## Non-negotiable principles

1. **One H1 per page, unique titles and descriptions per URL.** Never duplicate across pages. See `references/meta-tags.md` and `references/headings-intent.md`.
2. **Intent first, keywords second.** Match the query type before optimizing wording. See `references/headings-intent.md`.
3. **Structure for scanning.** Summary, TOC, headings, tables, and lists carry the argument. See `references/content-blocks.md`.
4. **Links build topics, not just pages.** Every page belongs to a cluster with descriptive anchors. See `references/internal-linking.md`.
5. **Ask when intent or audience is ambiguous.** Do not guess transactional versus informational intent.

## Workflow (summary)

1. **Audit metadata and headings** — check uniqueness, length, and title-versus-H1 split. See `references/meta-tags.md` section 1 and `references/headings-intent.md` section 1.
2. **Match intent** — label the query type and reorder sections to answer it first. See `references/headings-intent.md` section 2.
3. **Restructure blocks** — add TLDR, TOC, tables, lists, FAQ, and CTA placement. See `references/content-blocks.md`.
4. **Wire the cluster** — add internal links with descriptive anchors and confirm crawl depth. See `references/internal-linking.md`.

See `references/meta-tags.md`, `references/headings-intent.md`, `references/content-blocks.md`, `references/internal-linking.md` for detail.
